The essentials

少一点打扰，多一点
属于你的阅读节奏。

从文稿库到阅读页，RoomyNote 将常用操作放在自然的位置，让工具为思考服务。

01 / READ

沉浸式阅读

白色页面、柔和背景与清晰的工具栏，让注意力留在正在阅读的内容上。

02 / WRITE

自然手写批注

使用 Apple Pencil 直接在 PDF 页面上书写、标记和整理想法，保持阅读的连续性。

03 / EXPAND

让页面继续延展

需要更多空间时，向页面外扩展，让解题过程、课堂笔记与思维草稿自然展开。
